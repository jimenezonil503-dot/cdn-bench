01 /

产品定位

Google Cloud CDN 依托 Google 全球边缘网络，支持来自任意 HTTP 源站的内容，并提供缓存键、TTL、Cloud Armor、日志与指标等控制。

交付定位Google 全球边缘
安全方向Cloud Armor 集成
接入与源站HTTP 源站兼容
02 /

公开产品能力

  • 支持 Compute Engine、Cloud Storage、GKE 及外部 HTTP 源站
  • 缓存键、TTL 与路由的细粒度控制
  • 可与 Cloud Armor、Cloud Logging、Monitoring 结合
03 /

适用场景

Google Cloud、跨云或自有源站项目

04 /

编辑解读

Google Cloud CDN 可以作为 Google Cloud 或其他 HTTP 源站的候选。应先定义缓存键、TTL 和隐私边界，再比较不同地区访问、回源量与日志明细。

05 /

决策前需要确认

  1. 缓存键与 TTL 是否符合业务更新频率？
  2. 外部 HTTP 源站、日志和 Cloud Armor 如何组合？
风险提示

Cloud CDN 需要结合负载均衡、源站和 Google Cloud 计费模型理解；Media CDN 是另一类媒体交付产品。
