产品定位

CDN5 官网将高防 CDN、DDoS / CC 防护、WAF 与游戏 SDK 盾放在核心产品位置，适合把安全防护和内容加速一起评估的业务。

公开产品能力

  • 高防 CDN、Web 防火墙与高防 IP 产品线
  • 官网套餐列出 DDoS、CC、WebSocket 与全球地区等能力项
  • 提供中文、English、日本語入口
03 /

适用场景

游戏、媒体、API 与需要高防接入的项目

04 /

编辑解读

CDN5 适合从防护需求切入候选清单。除静态文件加载体验，还应在合同和测试环境中分别核对攻击清洗策略、回源稳定性以及不同地区的实际访问结果。
